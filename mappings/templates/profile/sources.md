# Source References

Record the primary evidence for this profile.

| Field | Description |
| --- | --- |
| Source identity | Repository or document URL |
| Revision | Tag and immutable commit, or an equivalent fixed document version |
| Location | Document path, section, table, or instruction definition |
| Dates | Source/event date and access date |
| Supported claim | The mapping rule or parameter justified by the source |
| Limitations | Conflicts, incomplete evidence, or version restrictions |

Distinguish approved text, draft snapshots, open proposals, implementation code, and plans. A source's maturity and a mapping's maturity are separate.

Connect each claim to [profile metadata](profile.yaml) and the relevant register, operand, lowering, or numerical definition. Preserve prior references when revising the profile.
