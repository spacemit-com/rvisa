# [VME](https://github.com/riscv/riscv-isa-manual/pull/2997) Profiles

No profiles are currently registered.

A registered profile identifies the RVISA version, upstream specification revision, target constraints, mapping revision, supported subset, and verification evidence. The profile identifier remains stable across editorial changes; semantic changes are recorded in its revision history.

Use one directory per profile and link it from this index when its identity and scope are defined. The [document format](../../templates/profile/README.md) and [mapping contract](../../contract.md) apply.

Return to the [mapping guide](../README.md).
