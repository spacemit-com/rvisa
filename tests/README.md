# Maintenance Tool Tests

This directory covers the behavior of repository maintenance tools.

Tests should exercise meaningful valid and invalid documents, metadata, links, anchors, and generated outputs. Temporary input files allow a test to validate actual tool behavior rather than mirror its implementation.

Shared language and target obligations belong in [conformance/](../conformance/README.md). Frontend and dialect tests remain with their respective modules.

Maintenance-tool test suites are under development; no executable test entry point is currently provided here.
